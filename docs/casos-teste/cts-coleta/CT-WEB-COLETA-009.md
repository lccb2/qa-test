## CT-WEB-COLETA-009 - Deve permitir pré-visualização da coleta

| Atributo | Descrição |
|---|---|
| **Status Esperado** | Sistema deve exibir JSON da coleta |
| **Prioridade** | Alta |
| **Tipo de Teste** | Auto |

### Funcionalidade: Pré-visualização

US  
> **Como** usuário  
> **Eu quero** visualizar os dados antes de enviar  
> **Para que** confirmar que estão corretos  

---

### Cenário: Deve permitir pré-visualização da coleta

**Dado** que preenchi os campos da coleta  
**Quando** clico em "Pré-visualizar"  
**Então** o sistema deve exibir os dados em formato JSON
